# M6 · 多 Agent 协作

| | |
|---|---|
| **层** | L1 扩展 |
| **工期** | 4–5 周（约 20–24 pd） |
| **前置** | M2（权限与账本必须先稳） |
| **并行** | 可与 M5 并行 |
| **特性开关** | `subAgents` |

## 目标

从「一个 Agent 串行干完」升级为「主 Agent 拆解任务，派发给专职子 Agent 并行执行」。

⚠️ **这是优先级最低的里程碑，也是最容易做过头的一个。** 在 M1–M5 没有全部稳定之前不要开工。多 Agent 带来的收益（并行提速、专职提质）远小于它带来的复杂度（状态同步、成本放大、调试困难），只有当单 Agent 确实成为瓶颈时才值得做。

## Demo（验收标准）

> 交办：「把 `01-输入材料/` 里的 5 份客户访谈整理成需求文档。」
>
> 主 Agent 判断可并行，派发 5 个子 Agent 各读一份并提炼要点，UI 上能看到 5 条并行的执行线，全部完成后主 Agent 汇总成文。
>
> 总耗时明显短于串行，且任一子 Agent 失败不影响其他，主 Agent 能据此调整。

## 设计原则

在写任何代码之前先定死这四条，它们是防止复杂度失控的护栏：

1. **确定性编排优先，自由讨论最后**
   优先做「主 Agent 拆解 → 并行执行 → 汇总」这种可预测的结构。**不做**多个 Agent 自由对话直到达成共识的模式 —— 那种模式成本不可控、结果不可复现、失败难以定位。

2. **子 Agent 是受限的**
   子 Agent 的工具集是主 Agent 的子集，权限只能更严不能更宽。子 Agent **不能再派发子 Agent**（只允许一层嵌套），否则任务树深度不可控。

3. **成本必须有硬上限**
   整个任务树共享一个 token 预算。超出即中止，不是"尽力而为"。

4. **每个子 Agent 独立留痕**
   子 Agent 的运行进各自的账本，通过 `parentRunId` 关联。不合并成一条流水，否则无法定位问题。

## 任务清单

### A. 子 Agent 运行时（6 pd）

| # | 任务 | 产出文件 | 估时 |
|---|---|---|---|
| M6-01 | `SubAgentSpec` 类型：角色、工具子集、模型、预算 | `src/lib/engine/sub-agent/types.ts` | 1pd |
| M6-02 | 子 Agent 生成器：复用 `runQuery`，独立 context | `src/lib/engine/sub-agent/spawn.ts` | 2pd |
| M6-03 | 并发调度：并行度上限、队列、失败隔离 | `src/lib/engine/sub-agent/scheduler.ts` | 2pd |
| M6-04 | 结果聚合：结构化返回给主 Agent | 同上 | 1pd |

M6-02 的关键：子 Agent 就是一次嵌套的 `runQuery`，不要写第二套循环。它与主 Agent 的差别只在 context（工具子集、预算、system prompt），不在机制。

| # | 任务 | 产出文件 | 估时 |

## 风险

| 风险 | 概率 | 应对 |
|---|---|---|
| **成本放大失控**（5 个子 Agent = 5 倍 token） | 高 | 任务树硬预算；UI 实时显示累计成本；默认并发上限保守 |
| 主 Agent 滥用派发（简单任务也拆） | 高 | `dispatch_agent` 的 description 里写明使用门槛；提供成本反馈让模型意识到代价 |
| 并发状态同步 bug | 中 | 子 Agent 完全隔离，只通过返回值通信，不共享可变状态 |
| 孤儿运行 | 中 | M6-19 作为强制测试用例 |
| 调试困难 | 中 | 每个子 Agent 独立账本 + 任务树视图 |
| 做过头，变成 Agent 编排平台 | 中 | 严守设计原则第 1 条；[00-vision-and-scope.md §5](../00-vision-and-scope.md) 明确不做可视化编排 |

## 完成定义

- [ ] Demo 能当着人跑通，且并行确实比串行快
- [ ] 5 路并发结果不串台
- [ ] 任一子 Agent 失败不影响其他，主 Agent 能感知并调整
- [ ] 停止主 Agent 后无任何孤儿运行
- [ ] 预算耗尽时全树立即中止
- [ ] 多个子 Agent 同时请求权限时，确认入口是合并的
- [ ] `flags.subAgents = false` 时回退到单 Agent
