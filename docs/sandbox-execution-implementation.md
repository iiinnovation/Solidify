> 目标：[沙箱执行面设计](sandbox-execution-plane-design.md)

## 当前工作区证据

- macOS 26.6.2 / x86_64；系统存在 /usr/bin/sandbox-exec。
- Homebrew 安装已结束（因链接/postinstall 告警返回非零）；已实际确认 Tesseract 5.5.3、pdfinfo 26.09.0 可启动，pdftoppm 和 chi_sim/eng 语言包存在。此安装不构成面向用户的组件分发方案。
- 直接复用旧版最小 profile 无法启动 dyld。显式导入系统 dyld-support.sb、限定执行路径后，外层 true 探测退出 0。
- 已构建实际 solidify 应用二进制，并通过 3 项真实 Seatbelt/监督测试：授权输入读取、work 写入；拒绝其他输入、输入写入、额外可执行文件、fork 和本机 TCP；超时、主动取消、父进程 SIGKILL 后回收。父死亡夹具先确认转换器已运行，再结束其直接父进程，等待 worker 在 kill/wait 和输出管道回收后返回 Cancelled。
- 测试限定于上述系统及夹具，不代表 OCR 依赖、UDP/代理路径、任意 Shell 或完整平台矩阵已验收。监督进程自身被强制终止等故障仍需独立评估。

## 本地验证命令

普通单元测试：

~~~sh
cargo test --manifest-path src-tauri/Cargo.toml sandbox_exec --lib
~~~

真实 Seatbelt 测试独立执行，不能在已经禁止嵌套 sandbox 的 runner 内把失败当作通过：

~~~sh
cargo build --manifest-path src-tauri/Cargo.toml --bin solidify
cargo test --manifest-path src-tauri/Cargo.toml live_ --lib -- --ignored --nocapture
~~~

真实测试必须先验证允许的输入能够读取，再验证禁止路径读取失败，避免因执行器完全启动不了而得到假阳性。

2026-09-06 验证：Rust 全量库测试 86 通过、4 忽略，其中沙箱普通测试 12 通过；忽略项为 3 项真实平台测试及 1 项仅供子进程调用的辅助夹具。上述真实测试单独执行 3 通过，git diff --check 通过。编译仍有未接入模块的 dead_code 警告，不能据此宣称任务功能已经可用。

同日后续：新增组件清单校验与文本结果收集器后，全量库测试 92 通过、4 忽略。进一步补充特殊文件拒绝：使用非阻塞打开及描述符类型检查，防止组件路径被 FIFO 替换时卡住验证线程。真实 OCR 转换尚未进行，不能用此轮单元测试代替中英文图片/PDF 验收。

## 固定转换流程接入记录

本轮验证：Rust 全量库测试 99 通过、4 忽略，git diff --check 通过。新增图片/PDF 流程测试使用模拟转换器；之前的真实 Seatbelt 测试结论不扩大为 OCR 端到端成功。

- 图片：父端仅检查 PNG/JPEG 文件头及尺寸，不展开完整像素；Tesseract 由监督器启动，固定 chi_sim+eng、LSTM、PSM 3 和 stdout 文本输出。参数依据本机 Tesseract 5.5.3 帮助及 [官方命令行说明](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html)。文件头使用 image 0.24.9 的 PNG/JPEG 功能，关闭其他格式；该版本匹配项目声明的旧 Rust 最低版本，发布前须一并核查依赖安全及升级策略。
- PDF：参数及输出格式核对了 Homebrew 下载的 Poppler 26.09.0 源码包中的 utils/pdfinfo.1、pdftoppm.1、pdfinfo.cc。先检查所有拟处理页面的 CropBox 尺寸，再以固定 150 DPI、cropbox、singlefile、PNG 逐页渲染。重复/缺失的元数据字段拒绝，避免被伪造字段覆盖。
- 每一步调用后的 stdout/stderr 都计入同次转换预算；准备、探测、渲染、OCR 共用单次时限。中间图片按精确文件名回收，不进入用户目录。任何页面失败都不产生 complete 结果。
- 模拟执行只验证控制流、参数、来源及预算，不能验证字体/动态库/语言包是否在实际沙箱内可读。外部工具仍未注册到任务，后端 IPC/租约互斥、页进度事件和真实图片/PDF 转换验收待完成。
- Homebrew 安装已结束，曾报告 OpenSSL/GnuPG postinstall 未完成、Python 3.14 与现有 /usr/local/bin 链接冲突；没有执行覆盖链接或删除现有 Python 的建议。Homebrew 自动清理了部分旧依赖版本及缓存（可重新安装/下载）；项目文件未受该清理影响。
- 首次真实 OCR 测试揭示 Homebrew 动态库别名路径无法通过当前严格 profile。测试组件改为复制到独立临时目录、逐文件重定位并 ad-hoc 签名；没有改动 Homebrew 安装文件，没有放宽目录级读取授权。这为正式组件包的重定位要求提供了证据，不能替代发行签名/公证。
- 重定位后实际 Tesseract 已在 Seatbelt 内加载 chi_sim+eng，并识别程序生成的英文 SOLIDIFY 图片。此证据仅证明英文识别和双语言数据加载，中文图像、真实扫描 PDF 仍待验收。
- 最新验证进一步通过完整图片管线：可信开发清单 SHA 校验 → 实际应用 worker/监督 → Tesseract → 页文本和来源回传。全量库测试 100 通过、5 忽略；新增真实图片 OCR 测试单独执行通过，git diff --check 通过。新增任务读取边界测试覆盖文件/父目录链接、目录及 FIFO 拒绝。

2026-09-07 授权接入：同一 task/run/file/method 默认只允许一次尝试，换 callId 或批次不能重置；显式新 run 可以重试。新增数据库授权测试覆盖伪造/跨 run 租约、未领取文件、类型不匹配、计划排除、文件已出队及到期拒绝。最新 Rust 全量库测试 106 通过、5 忽略；前端取消与 store 测试 19 通过，TypeScript 检查通过。客户端 AbortSignal 发送后端取消请求，但持续等待转换结束并丢弃晚到结果，不把 Promise 取消当作进程已退出。
