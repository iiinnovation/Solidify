# Draw.io 提交检查清单

## 结构

- 必须存在 `mxfile`、`diagram`、`mxGraphModel`、`root`，并保留 id 为 `0` 和 `1` 的根节点。
- 所有 vertex、edge 的 id 唯一；edge 的 source/target 和所有非根 parent 必须存在。
- XML 特殊字符已转义，文件可以被标准 XML 解析器解析。

## 内容

- 节点名称表达业务职责，不使用“模块1”“服务A”等无意义占位。
- 简单图没有空容器、孤立节点、重复节点或无依据的技术组件。
- 外部系统与内部组件有明确视觉分区。

## 几何

- 所有节点完全位于画布及父容器内，swimlane 子节点不覆盖标题区。
- 任意两个同级节点不重叠；页面没有大片无意义留白。
- 连线不穿过非目标节点、容器标题或标签；协议文字不互相遮挡。
- 主调用方向一致，跨层连线优先垂直，同层连线优先水平。
