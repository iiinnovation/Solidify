# 汇报大纲

第一步读取 `reference/legacy-guidance.md` 的完整大纲格式。根据受众和汇报类型组织章节、建议时长、关键数据、风险、下一步和演讲备注。信息已明确时直接产出，否则只列最少的待确认项。

## 提交前自检

开头先给受众需要记住的核心结论，各章节必须服务于该结论。建议时长总和与会议时长一致，关键数字标明数据来源或占位负责人。风险之后必须有决策请求或下一步，避免只有栏目名称没有观点。
